# Flip Scripts

Community-maintained custom command scripts for [Flip](https://tenonstudio.github.io/apps/flip/).

> **Warning**  
> Flip custom commands run shell scripts with your user permissions. Review every script before importing it. Never run scripts that ask for your password, tokens, cookies, or unrelated files.

## Status

This repository is a curated collection, not a marketplace. Every contribution is reviewed before it is merged.

## Layout

```text
scripts/
├── system/         # system settings and maintenance
├── media/          # audio, music, display
├── productivity/   # notes, apps, workflow
└── fun/            # harmless experiments
schema/             # import format documentation
```
